# VSTG.RTW — Servicios Digitales

Ecommerce de servicios digitales: streaming, crecimiento en redes y edición profesional.

## Stack
- HTML5 semántico
- CSS3 (paleta monocromática negra / blanca)
- JavaScript Vanilla (sin frameworks)

## Estructura
```
vstg-rtw/
├── index.html      # Estructura del sitio
├── styles.css      # Estilos y sistema de diseño
├── script.js       # Carrito, filtros y animaciones
└── README.md       # Documentación
```

## Cómo usarlo
1. Abre `index.html` en tu navegador, o
2. Sirve la carpeta con cualquier servidor estático (GitHub Pages, Netlify, Vercel).
